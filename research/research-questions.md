# Research Questions

- **RQ1 — Provenance-bound adaptation:** Can an agent system change while preserving traceable provenance, validity and rollback?
- **RQ2 — Controlled autonomy:** Can exploration and self-generated task candidates increase without silently expanding execution authority?
- **RQ3 — Core / experience separation:** Does separating a small directly loaded rule layer from a larger uncertain retrieval layer reduce drift and improve reproducibility?
- **RQ4 — Role separation:** Do separated collection, curation, verification, implementation and audit roles improve error discovery and provenance retention?
- **RQ5 — Transition structures across scales:** Which invariants survive across micro-, meso- and macro-level workflows, and where does the analogy break?
- **RQ6 — Internally triggered task formation:** Which defined state changes reproducibly create useful task candidates, and when should they decay or be discarded?
- **RQ7 — Stability without hard-coding:** Can hypothesized signatures emerge under predefined post-hoc measurements without being injected as tuning targets?
