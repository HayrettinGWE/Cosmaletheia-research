# Security and Disclosure

Please do not publish secrets, credentials, personal data, raw private conversations, private source mappings, internal workstation paths or other sensitive provenance material in issues or pull requests.

This repository intentionally exposes only a curated public research surface.

If you believe you found sensitive material, do not repost it publicly. Contact the repository owner privately through an available GitHub contact channel.

No unsolicited code or research contributions are accepted until a contribution policy is published.
