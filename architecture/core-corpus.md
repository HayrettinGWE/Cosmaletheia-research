# Core / Corpus Separation

## Core
A small, versioned rule and definition layer intended to be loaded directly. The Core is not a popularity vote over retrieved material.

## Corpus
A larger experience and evidence space that may contain incomplete, conflicting, superseded or uncertain material. Retrieval provides context and evidence; it does not automatically create canonical truth.

## Research motivation
Compare retrieval-only operation with Core + Corpus + regression under identical tasks and evaluate reproducibility, evidence fidelity and drift.
