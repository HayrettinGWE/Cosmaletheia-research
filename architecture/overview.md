# Architecture Overview

CosmAletheia separates:

```text
Possibility / exploration
        ↓
Binding / verification / authorization
        ↓
Effect
```

**Exploration** may generate alternatives, questions, hypotheses and proposed changes. It does not create truth or authority.

**Binding** checks provenance, scope, validity, role, version and constraints.

**Effect** represents consequential execution or publication and requires separate authorization.

Principles: provenance before promotion; stable core distinct from uncertain experience; candidate before canonical state; role separation; explicit validity/authorization boundaries; replay/regression where feasible; failures and rejected candidates remain informative; local similarity does not grant global authority.

This public overview intentionally omits private implementation details and source mappings.
