# Agent Roles

Candidate separated functions:

- **Collector** — gathers and structures input
- **Curator** — formulates candidates
- **Critic / Verifier** — searches for contradiction, missing evidence and invalid scope
- **Builder** — implements approved technical changes
- **Auditor** — evaluates regression, provenance and policy compliance

Role separation is an architectural hypothesis and evaluation target. It does not require each role to be a separate model.
